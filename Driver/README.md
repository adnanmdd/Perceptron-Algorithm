 <h2>Driver Fatigue Detection using Perceptron Algorithm</h2>

<p>
This project implements a Driver Fatigue Detection system using the Perceptron Algorithm, a simple supervised machine learning model used
for binary classification. The system helps identify whether a driver is alert or fatigued based on behavioral and visual input data.
</p>

<h3>Project Overview</h3>

<p>
The model analyzes features such as eye closure duration,eye blink rate, steering variability and lane direction. These inputs are processed
and classified into two categories:
</p>

<ul>
    <li><strong>-1:</strong> Alert Driver</li>
    <li><strong>1:</strong> Fatigued Driver</li>
</ul>

<h3>Applications</h3>

<p>
    This system can improve road safety by reducing accidents caused by driver
    drowsiness in cars, trucks, and public transport vehicles.
</p>
