<h2>Employee Eligibility Criteria - Perceptron Approach</h2>

<p>
This project addresses the employee eligibility problem as a binary classification task using the Perceptron algorithm. 
The objective is to determine whether an employee is eligible for promotion or not based on three key features.
</p>

<h3>Overview</h3>
<p>
The model uses three input features: experience, performance, and projects. These features are numerically encoded and fed into a perceptron, which learns a decision boundary to classify employees.
</p>

<h3>Outcome</h3>
<ul>
    <li>Reduced manual bias in decision-making</li>
    <li>Fast and scalable predictions</li>
    <li>Simple and interpretable model</li>
</ul>
