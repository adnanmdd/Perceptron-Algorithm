<h3>Perceptron Learning Algorithm — Overview</h3>
<p>
The <strong>Perceptron Learning Algorithm (PLA)</strong> is a simple supervised learning method used for
<strong>binary classification</strong>. It works by finding a linear decision boundary (a line or hyperplane)
that separates data points into two classes.
</p>

<p>
The perceptron learns by adjusting weights based on prediction errors:
</p>
<ul>
  <li>If prediction is correct → no update</li>
  <li>If prediction is incorrect → update weights</li>
</ul>
